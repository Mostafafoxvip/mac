# الوثائق

هذا المجلد يحتوي على الوثائق الإضافية والشروحات التفصيلية.

## المحتويات المخطط لها:
- أدلة الاستخدام التفصيلية
- شروحات السكريبتات
- أمثلة عملية
- نصائح وحيل لاستخدام macOS
- دروس فيديو (روابط)

## الاستخدام:
ستتم إضافة الوثائق الإضافية تدريجياً مع تطور المشروع.

## المساهمة:
نرحب بأي إضافات أو تحسينات للوثائق. يمكنك:
1. إضافة شرح لسكريبت معين
2. كتابة دليل استخدام لأداة
3. مشاركة نصائح مفيدة
4. إضافة أمثلة عملية

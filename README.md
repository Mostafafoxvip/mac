## 📖 نبذة عن المشروع

### 🎯 أهداف المشروع
- ⚙️ تخصيص بيئة عمل macOS
- 🚀 أدوات لزيادة الإنتاجية

## 📦 التثبيت

### المتطلبات الأساسية
- جهاز Mac يعمل بنظام macOS
- صلاحيات المسؤول (Administrator)
- اتصال بالإنترنت

### خطوات التثبيت

1. **استنساخ المستودع**
```bash
git clone https://github.com/Mostafafoxvip/mac.git
cd mac
```

2. **منح صلاحيات التنفيذ للسكريبتات**
```bash
chmod +x *.sh
```

3. **تشغيل السكريبت المطلوب**
```bash
./setup.sh
```

## 📝 الاستخدام

### الأدوات المتوفرة

#### 🔧 سكريبت الإعداد الأولي
```bash
./setup.sh
```
يقوم بإعداد البيئة الأساسية وتثبيت الأدوات الضرورية.

#### ⚡ سكريبتات الأتمتة
```bash
./automation/
```
مجموعة من السكريبتات لأتمتة المهام اليومية.

#### 🎨 التخصيصات
```bash
./customizations/
```
إعدادات مخصصة للواجهة والثيمات.
